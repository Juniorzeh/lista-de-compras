# 🛒 Lista de Compras

Aplicação web desenvolvida para **gerenciar uma lista de compras**, permitindo adicionar, remover e organizar itens de forma simples e prática.

## 📌 Objetivo

O projeto tem como objetivo:

- praticar JavaScript na manipulação do DOM
- desenvolver lógica de aplicações reais
- criar uma solução simples para organização de compras do dia a dia

## 🚀 Funcionalidades

- ➕ Adicionar itens à lista
- ❌ Remover itens
- ✏️ Editar itens (se aplicável)
- 📋 Visualizar lista organizada
- 🔄 Atualização dinâmica da interface

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
